# CodeAlpha_Hangman_Game
## Project Description
This is a simple text-based Hangman Game developed using Python as part of the CodeAlpha Python Programming Internship.

The player must guess a randomly selected word by entering one letter at a time.

## Features
- Random word selection from 5 predefined words
- Maximum 6 incorrect guesses allowed
- Displays correctly guessed letters
- Shows remaining attempts
- Validates user input
- Detects repeated guesses
- Displays winning and losing messages

## Technologies Used
- Python 3
- Python IDLE

## How to Run
1. Download the Hangman_Game.py file.
2. Open the file using Python IDLE.
3. Press F5 to run the program.
4. Enter one letter at a time to guess the hidden word.
